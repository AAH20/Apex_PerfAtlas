# Partner evaluation procedure

A paid evaluation should define the customer's workload and acceptance procedure before optimization begins. Contract size is a commercial outcome, not a benchmark metric.

1. Specify the protocol/model/query version, data rights, required semantics, traffic and failure behavior.
2. Freeze the baseline hardware, firmware, software, placement, precision and load schedule.
3. Agree measurement boundaries, instrumentation, uncertainty and repeated-trial policy.
4. Establish correctness, loss, tail latency, recovery and operational acceptance gates.
5. Record candidate changes and validate retained artifacts independently where agreed.
6. Price the deployment from scoped quotes, licenses, support and operating assumptions.
7. Deliver source/build identities, reproduction commands, reports, limitations and integration tasks.

Advanced hardware, Exegy IP or an exchange environment requires actual partner access and applicable terms. Neither a catalogue entry nor a contract proposal establishes that access. Private adapter interfaces keep restricted materials outside the public repository.
